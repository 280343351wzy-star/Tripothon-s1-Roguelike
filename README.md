# Tripothon S1: 3D Roguelike 项目技术预备仓库

## 👤 主程简介
*   主攻方向：游戏客户端程序开发、系统架构、AI辅助开发管线搭建。
*   技术栈：Unity / UE5 、面向对象设计、状态机、对象池。

## 🎯 技术目标（10天极限开发）
我们的目标是打造一个类似《Risk of Rain 2》的 3D Roguelike 动作游戏。作为主程，我将在项目中负责：
1.  **核心手感调优**：实现流畅的第三人称移动、射击与闪避手感（基于成熟控制器二次开发）。
2.  **肉鸽核心系统**：搭建高可扩展的道具系统，实现**乘法叠加**的Buff机制。
3.  **程序化地图与难度曲线**：实现随机关卡拼接与动态刷怪难度曲线。
4.  **性能优化**：负责对象池管理与内存优化，确保 Demo 流畅运行。

## 🛠️ AI 辅助开发预案
*   **代码辅助**：计划使用 Cursor / Claude 3.5 加速基础模块、UI 逻辑与工具脚本的开发。
*   **资产对接**：负责将 Tripo3D 生成的 AI 模型接入引擎，解决拓扑与材质渲染问题。
*   **AI 辅助美术/音效**：配合策划队友，使用 AI 工具（如 Midjourney / Suno）批量生成道具图标与音效，确保风格统一。
